# Melbourne Property Intelligence 

A suburb and LGA level analysis of rental yield, rental demand, and interest rate sensitivity across Melbourne, Australia. 

This project integrates publicly available rental, price, and demand data to examine the trade-offs between income return, demand stability, and financing risk in residential property investment. Using gross rental yields, active rental bonds as a demand proxy, and interest rate stress scenarios, it highlights how different parts of Melbourne exhibit distinct risk-return profiles. 

Key features: 
- Suburb level gross rental yield analysis 
- LGA level rental demand assessment using RTBA active bonds 
- Yield-demand quadrant framework 
- Interest rate sensitivity and cash-flow resilience analysis 
- Clear, investor-oriented insights and visualisations 

An interaction Streamlit dahsbord for suburb level exploration is under development.
